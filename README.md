# صفحه تماس رقیه خاتون

این پوشه برای انتشار مستقیم در GitHub Pages آماده است.

## فایل‌ها
- `index.html`
- `style.css`

## انتشار روی GitHub Pages
1. یک Repository جدید در GitHub بسازید.
2. فایل‌های `index.html` و `style.css` را در شاخه اصلی Repository آپلود کنید.
3. از بخش **Settings > Pages**، انتشار را روی **Deploy from a branch** بگذارید.
4. Branch را روی `main` و Folder را روی `/root` قرار دهید و Save کنید.
5. بعد از فعال شدن Pages، لینک نهایی را برای ساخت QR Code استفاده کنید.
